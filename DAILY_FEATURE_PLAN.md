# Daily Feature Plan — 2026-09-30

## Feature: AI Coach Page

**One-line description:** A dedicated `/coach` page that surfaces the fully-built `GET /ai-insights/{user_id}` backend endpoint into a personalized coaching experience — ranked improvement areas, benchmark comparisons, drill tips, and strengths.

---

## User Value

Every golfer wants to know *what to work on next*, not just a wall of statistics. Right now the app collects rich performance data but the AI analysis engine — already running on the backend — is completely invisible to users. There's no route, no nav item, no page.

Building this page gives golfers:
- **Prioritized improvement areas** ranked by stroke-saving potential (GIR, putting, scrambling, par-type performance)
- **Benchmark context** — "you're a 15 HCP; average 15 HCP players make 22% of GIRs; you're at 18%" is actionable, a raw number isn't
- **Drill tips** (already generated by the AI service) surfaced inside each insight card
- **What-if scenarios** (already in the schema) — "fixing your three-putt rate to tour average would save ~2.1 strokes per round"
- **Strengths** — what they do better than peers, which builds confidence alongside the gaps

This is the kind of feature that turns casual users into daily active users. It's also the key differentiator vs. Arccos, GolfLogix, and other tracking apps that give data but not coaching.

### API call

```typescript
// frontend/src/lib/api.ts
getAIInsights: async (userId: string, params?: { limit?: number; target_handicap?: number }) => {
  const qs = new URLSearchParams();
  if (params?.limit) qs.set("limit", String(params.limit));
  if (params?.target_handicap != null) qs.set("target_handicap", String(params.target_handicap));
  const res = await fetch(`/api/ai-insights/${userId}?${qs}`, { credentials: "include" });
  if (!res.ok) throw new Error(await res.text());
  return res.json() as Promise<AISuggestionsResponse>;
}
```

### Rate limit UX
The endpoint has a sliding-window rate limiter (12 req/hr per IP, 20 req/hr per user). The page should:
- Cache the response in React Query with `staleTime: 1000 * 60 * 30` (30 min) to avoid hammering the endpoint
- On a 429 response, show "AI analysis refreshes hourly — check back soon" rather than a generic error

### Design System notes
Follow existing patterns from `CLAUDE.md`:
- Cards: `bg-white rounded-2xl border border-gray-100 shadow-sm p-5`
- Section labels: `text-[11px] font-bold text-primary/50 uppercase tracking-[0.18em]`
- Priority scores 8–10 → red accent; 5–7 → amber; < 5 → gray
- Category group colors: Ball Striking → blue, Short Game → green, Putting → purple, Mental → amber
- Animate insight cards in with `ScrollSection` staggered entrance (already used in analytics)
